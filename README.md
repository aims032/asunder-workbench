## Layout

```
AsunderRN/            The React Native app (iPhone, Android, web preview). Has its own README.
  src/core/           Pure logic in TypeScript, ported file for file from AsunderCore. Tuning.ts is here.
  src/                The app: dial, audio, haptics, screens.
Asunder.xcodeproj/    The Swift app's Xcode project.
Asunder/              The Swift iPhone app: screens, audio engine, haptics.
                      (Synced folder: new .swift files here join the app automatically.)
AsunderCore/          Pure logic as a Swift package: band, clock, dial physics, Tuning.swift.
                      No UI or audio imports, so it's testable anywhere.
docs/                 Design docs (source of truth).
materials/            Poetry, channel maps. Reference only.
.github/workflows/    CI: runs both sets of tests and builds the Swift app.
```

Why the split between "core" and "app": the rules every phone must compute identically (clock, wrap, week rule) live in the core, where they're tested without a phone. The app layer just reads from it and makes sound and pictures. Both versions are built this way, and a test in `AsunderRN` checks that the TypeScript core gives the same answers as the Swift core.

## The Swift app: first run (on your Mac)

1. Install Xcode 16 or newer.
2. Open `Asunder.xcodeproj`.
3. Click the **Asunder** project → **Asunder** target → **Signing & Capabilities**:
   - Team: pick your Apple Developer account.
   - Bundle Identifier: change `com.example.asunder` to something you own, e.g. `com.yourname.asunder`.
4. Plug in your iPhone, pick it as the run destination, press **⌘R**.
   You should see a black screen with `ASUNDER` and `0.25` (that number proves the core package is linked). The black screen is a placeholder, not the design.
5. **⌘U** runs the AsunderCore tests.

From the terminal, core tests also run with: `swift test --package-path AsunderCore`

## If the Swift project won't open

It was written by hand, not generated by Xcode, so if Xcode refuses it:
File → New → Project → iOS App (SwiftUI, name `Asunder`), save it over this folder, delete its generated `ContentView.swift`/`AsunderApp.swift`, then File → Add Package Dependencies → Add Local → pick `AsunderCore`.
